# 冒韵东主任：卵巢过度刺激综合征的注意事项

> 更新时间：2026-09-16 (UTC+8)

**导读：**
卵巢过度刺激综合征（OHSS），是促排卵的梦魇，也是试管婴儿治疗中卵巢刺激的大敌，战场上知己知彼才能获胜。我们也得对OHSS知道得越多越好，才能具备战胜它的勇气和能力。今天我们请来了冒韵东主任给我们讲讲OHSS的注意事项。

**冒韵东主任：卵巢过度刺激综合征的注意事项**

江苏省人民医院生殖中心：冒韵东

在试管婴儿的治疗中或有排卵障碍的女性为了怀孕，用药物刺激排卵后，出现的一组由许多不适构成的表现，也称“综合征”。我们把它称为一种“并发症”，也就是出现了医生不希望在医疗中发生，但又发生了的问题。一般来说，没有促排卵就几乎没有卵巢过度刺激综合征。

**一、OHSS的程度分级**

OHSS分为轻、中、重度三个级别，轻度的发病率约为8%～23%，中度的发病率约为1%～7%，重度的可能低于0.5%，不过这并不是精确的发生率。

**二、OHSS好发于什么情况？**

1、促排卵治疗的最后，医生用一种叫绒毛膜促性腺激素（hCG）给您注射，有利于取卵，注射后的4～5天是早发型OHSS的高发期。

2、促排卵后怀孕的早期，胚胎分泌的hCG，会刺激卵巢分泌更多的细胞因子，造成迟发型OHSS的发生或原有的OHSS症状加重。

**三、OHSS的表现有哪些？**

卵巢会变得比正常时大许多，血液里的水分会透过小血管跑到肚子里（盆腔、腹腔）或肺的外面（胸腔），甚至会跑到皮肤下面，让身体很多部位肿起来。

患者会觉得肚子胀，不想吃东西，恶心和呕吐，腹泻，肚子变大，体重增加，小便少，喘气困难，甚至心慌，心跳加快，无法平睡等。

**四、什么情况要去医院就诊？**

作为病人可能无法判断OHSS的严重程度，如果您接受了促排卵治疗，又出现了前面所提到的各种不适，就应该及时到正规医院就诊，症状严重时应该看急诊：

1、如果您感到小肚子突然有很厉害的疼痛，尤其是在长时间憋尿再排尿后、用力排便或者突然改变体位后出现一侧或两侧下腹痛，有时还伴有严重的恶心，头晕，出冷汗，一定不要大意，应立即到正规医院看急诊，因为您可能出现了卵巢扭转或破裂，如不及时处理，超过24小时卵巢严重缺血坏死可能会不得切除卵巢。

2、也要注意有没有偏一侧的头、脖子、腰背部、胳膊或腿部的疼痛，如果有，也要及时就诊，检查血管里有没有产生血栓。如果长了血栓，需要及时处理，最严重时可以危及生命或留下难以治愈的后遗症，比如偏瘫等。

**五、哪些人容易发生卵巢过度刺激综合征？**

年轻、瘦小、有PCOS病史、OHSS病史的女性易发生OHSS，此外，容易过敏的女性也相对更容易患OHSS。

**六、OHSS如何预防？**

OHSS可以预防，有经验的医生会尽量防患于未然。

1、因为多囊卵巢综合征有超重/肥胖的无排卵患者，可以通过锻炼+饮食控制减体重而改善排卵，从而避免应用促排卵药物。
2、应用比较弱的促排卵药，而且尽可能减少药物的剂量；在正规医院由有经验的医生给您用药并接受B超的监测；如果以前做试管婴儿用常规的促排卵方案时发生过OHSS，则可在医生指导下改用微刺激/温和刺激/拮抗剂方案等低风险方案。
3、在促排卵过程当中如出现上述OHSS的症状，适时改变治疗方案，如：终止人工授精，采取严格的避孕措施，不用或减少hCG的剂量，在可能的情况下改用GnRH-a促卵泡排卵，IVF周期全胚冻存等。
4、促排卵过程中发现OHSS倾向的可以鼓励患者多饮水、高蛋白饮食，预防性的静脉补液，扩展血容量，防止血液浓缩。D-二聚体升高的可以加用低分子肝素抗凝治疗。

**七、卵巢过度刺激综合征治疗期间有哪些注意事项？**

轻度的没有太大危险，只在门诊治疗就可以好转，而中重度OHSS一般需要住院治疗，最严重的卵巢过度刺激综合征甚至可以危及生命！

 一般轻度的OHSS不需要住院治疗，只要注意自己的不适症状及严重程度，吃一些高蛋白的饮食，比如：瘦肉，鱼虾的肉，酸奶等；多喝水，注意小便的次数和量就可以了。如果不适症状加重且小便量少，就应该及时就诊。中-重度卵巢过度刺激综合征是需要住院治疗的。

 

OHSS的恢复时间一般无法预计，但程度越重或怀孕者可能需要较长的治疗时间。

1、患者应每天称体重，计量喝的液体，包括汤、果汁和水的量，以及小便的量，做好记录。
2、由于腹胀、喘气困难等，患者可能不想吃东西，但还是应该尽量吃一些容易消化的高蛋白饮食，少吃多餐，这样可以提高血里的蛋白含量，对疾病的治疗有益。
3、可以多喝一些水，每天至少在1000毫升以上，如果实在吃不了东西，水就不要喝太多，喝汤、果汁不能代替喝水。
4、在可能的情况下适当下地活动，即使躺在床上，也可以经常翻翻身，这样可以避免血液流动过慢而在血管里形成血栓，一旦形成，后果可能很严重。
5、及时如实的反映各种不适症状，以便医生判断病情的变化，必要时行胸腔/腹腔引流以减轻症状，千万不要因为害怕放管子而隐瞒或说轻胸闷、腹胀等症状。
